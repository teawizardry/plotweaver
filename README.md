# An Unofficial Plotweaver LaTeX Document Class

This document class and its accompanying packages help typeset homebrew documents in the style of the [Plotweaver RPG](https://www.plotweaverrpg.com/) and [Cosmere RPG](https://www.cosmererpg.com/) rule books. Documentation can be found in `plotweaver.pdf`. For general example usage, see `example.pdf` and its source `example.tex`. For an example of how to use this document class to create a character sheet, see `character-sheet.pdf` and its source `character-sheet.tex`.

This document class is currently under active development. Feedback or contributions are welcome.
